# Notification System

## Priorities
Normal: offers, credits, reviews, analytics and membership.
High: new Customer Request and urgent request actions.

## Flow
Customer Request → eligibility check → high-priority push → merchant action.
Reminders: +3m and +8m.
Expiry: +10m.

## Reliability
The request remains in the merchant inbox even if push delivery fails.
Push taps deep-link to the exact request.

## Merchant controls
- Accepting Requests
- Customer Requests ON/OFF
- Urgent Requests ON/OFF
- Reviews ON/OFF
- Credits ON/OFF
- Offers ON/OFF
- Quiet hours
