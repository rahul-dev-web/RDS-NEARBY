# Marketing Credits

## Earning
+10 credits for one qualified customer referral.

## Spending
50 credits → Boost Shop → 24 hours.
100 credits → Promote Offer → 3 days.

## Wallet
Balance is capped at 2,000.
Credits do not expire.

All balance changes are ledger-backed:
- referral_reward
- boost_spend
- promote_offer_spend
- admin_adjustment
- reversal

Client applications cannot directly mutate wallet balances.
