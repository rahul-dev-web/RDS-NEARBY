# RDS Nearby — Launch Plan

## Pilot
1 locality.
50–100 active shops.
500–1,000 real users.

Start with:
Grocery, Vegetable, Salon, Medical, Stationery, Fancy, Mobile.

## Acquisition
Primary: merchant QR, WhatsApp, customer referrals, public shop pages, offline QR/stickers.
Paid ads: ₹0 initially.

## Validation
Track:
- search → shop view → contact/reserve
- qualified referrals
- merchant credit usage
- request response rate
- repeat usage
- merchant acquisition value

Only after real merchant value is proven should ₹99/month Growth membership be introduced.
